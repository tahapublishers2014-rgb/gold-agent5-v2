# ایجنت طلا

داشبورد ایستا و فارسی برای تحلیل نماد پیوستهٔ آتی طلا `GC=F`. دادهٔ قیمت از Yahoo Finance عمومی گرفته می‌شود؛ API یا کلید پولی لازم نیست. `GC=F` نه قیمت نقدی `XAU/USD` است و نه نرخ اجرایی کارگزاری. داده می‌تواند تأخیری باشد و سری پیوستهٔ آتی نیز محدودیت رول‌اور و مشخصات قرارداد دارد.

## پرسش از ایجنت

پنل پرسش، متن را به دسته‌های «جهت بای/سل»، «دلیل صبر یا تعارض»، «سطوح ورود/حد ضرر/هدف» و «حجم و ریسک» تقسیم می‌کند و جواب مرتبط را از تحلیل فعلی می‌سازد. پاسخ‌گو محلی و قاعده‌محور است، گفت‌وگوی آزاد با مدل زبانی نیست و سفارش ثبت نمی‌کند. برای دادهٔ نمونه، نامعتبر یا بیش از ۴۰ دقیقه عقب‌افتاده، پیشنهاد ورود یا حجم اجرایی نمی‌دهد.

## حجم پوزیشن و هزینه‌ها

ماشین‌حساب حجم، سرمایه و درصد ریسک، ضریب قرارداد، اسپرد رفت‌وبرگشت، لغزش هر سمت و کمیسیون رفت‌وبرگشت را می‌گیرد. اندازهٔ نظری بر اساس ریسک دلاری تقسیم بر زیان هر لات تا حد ضرر به‌علاوهٔ هزینه‌ها محاسبه می‌شود. پیش‌فرض نمایشی ضریب ۱۰۰ دلار به‌ازای یک دلار حرکت قیمت برای هر لات، اسپرد ۰٫۵ نقطه، لغزش ۰٫۲ نقطه در هر سمت و کمیسیون صفر است؛ این اعداد قیمت بروکر نیستند و باید با مشخصات واقعی حساب جایگزین شوند. مالیات، تأمین مالی/سوآپ، مارجین و لغزش جهشی لحاظ نشده‌اند. دفتر معاملات نیز ضریب و هزینه‌های ذخیره‌شدهٔ محلی را در P&L تخمینی اعمال می‌کند.

## روش و محدودیت بک‌تست

workflow هفتگی `backtest-gold`، ۱۰ سال دادهٔ روزانهٔ Yahoo برای `GC=F` می‌گیرد. پارامترها ثابت‌اند: امتیاز خام/تعدیل‌شده با آستانهٔ ۲۵، ورود در بازشدن کندل پس از سیگنال، حد ضرر ۱٫۵ ATR، هدف ۲R، حداکثر نگهداری ۱۰ کندل، حد ضرر مقدم بر هدف در لمس هم‌زمان، و حذف معاملات هم‌پوشان. تاریخ به‌ترتیب ۶۰٪ آموزش، ۲۰٪ اعتبارسنجی و ۲۰٪ آزمون نهایی تقسیم می‌شود؛ پوزیشن از مرز بازه عبور نمی‌کند.

برای کمبود مشخصات واقعی کارگزاری، سه سناریوی هزینهٔ کم/پایه/فشار با فرض صریح اسپرد، لغزش و کمیسیون گزارش می‌شود؛ این‌ها سناریو هستند، نه کارمزد اعلام‌شدهٔ بروکر. افت سرمایه در منحنی فرضی با ریسک ثابت ۱٪ برای هر معامله محاسبه می‌شود. نتایج فرضی و توصیفی‌اند، نه پیش‌بینی یا تضمین سود. دادهٔ روزانه ترتیب لمس درون‌روزی را نشان نمی‌دهد؛ سری پیوستهٔ Yahoo نیز تاریخچهٔ قراردادهای قابل‌معامله، رول، مارجین، مالیات، تأمین مالی، اثر بازار یا قیمت اجرایی را کامل بازسازی نمی‌کند. نتیجه، به‌تنهایی مبنای ورود نیست.

## فعال‌سازی GitHub Actions

فایل‌های workflow در `.github/workflows/` هستند: `update.yml` برای داده و `backtest.yml` برای آزمون هفتگی. در GitHub از **Settings → Actions → General → Workflow permissions** نوشتن محتوا را فعال کن تا workflow بتواند JSON را commit کند. پس از انتشار فایل‌ها، در **Actions** اجرای دستی `update-gold` و `backtest-gold` را یک بار شروع کن. شکست اجرای داده یا بک‌تست عمداً workflow را قرمز می‌کند و به‌عنوان موفقیت گزارش نمی‌شود.

قیمت هر ۲۰ دقیقه درخواست می‌شود، ولی زمان cron GitHub تضمین‌شده نیست و Yahoo Finance نیز ممکن است محدودیت یا قطعی داشته باشد. صفحه هنگام بازبودن هر پنج دقیقه JSON را دوباره می‌خواند؛ این کار فقط نسخهٔ منتشرشده را تازه می‌کند، نه خود منبع قیمت را.

## مرز ایمنی

این سایت تحلیل و شبیه‌سازی است، نه مشاورهٔ مالی شخصی. دادهٔ عمومی و نتایج بک‌تست قیمت لحظه‌ای قابل‌اجرا نیستند. تصمیم نهایی و بررسی نماد، اسپرد، هزینه، مارجین و ریسک با کاربر است؛ سایت به بروکر متصل نیست و معامله‌ای اجرا نمی‌کند.
